# CK6132 普通车床故障手册

## 故障案例 1
- 设备型号：CK6132 普通车床
- 故障部位：主轴
- 故障现象：主轴运转时有异响，发出"嗡嗡"声
- 可能原因：
  1. 主轴轴承磨损严重，间隙过大
  2. 主轴电机底座松动
  3. 主轴箱齿轮啮合间隙过大
- 排查步骤：
  1. 关闭电源，打开主轴箱端盖，检查轴承是否有伤痕、烧蚀
  2. 用塞尺测量轴承间隙，超过 0.02mm 说明磨损严重
  3. 检查电机固定螺栓是否松动
  4. 检查齿轮啮合面是否有磨损、点蚀
- 解决方案：
  1. 轴承磨损 → 更换同型号轴承（型号 6207）
  2. 电机松动 → 紧固底座螺栓，扭矩 25N·m
  3. 齿轮间隙过大 → 调整齿轮垫片，保证侧隙 0.05-0.10mm

## 故障案例 2
- 设备型号：CK6132 普通车床
- 故障部位：进给系统
- 故障现象：走刀不均匀，忽快忽慢，出现爬行
- 可能原因：
  1. 进给箱齿轮磨损，传动不稳定
  2. 进给丝杠润滑不良，缺润滑油
  3. 进给挂挡拨叉磨损，啮合不到位
- 排查步骤：
  1. 检查进给箱润滑油油位，低于油窗 1/3 刻度需补充
  2. 打开进给箱端盖，检查齿轮齿面磨损情况
  3. 检查进给丝杠副是否有研伤、拉痕
  4. 挂挡后用手转动进给轴，确认是否有卡滞
- 解决方案：
  1. 润滑不良 → 补充 46 号液压导轨油至油窗 2/3 位置
  2. 齿轮磨损 → 更换磨损齿轮（齿数 47，模数 2）
  3. 拨叉磨损 → 更换拨叉总成

## 故障案例 3
- 设备型号：CK6132 普通车床
- 故障部位：刀架
- 故障现象：四方刀架换刀时卡死，不能转动
- 可能原因：
  1. 刀架内部定位销断裂
  2. 刀架锁紧螺母松动
  3. 刀架齿轮磨损严重
- 排查步骤：
  1. 关闭电源，手动松开锁紧螺母
  2. 拆下刀架上盖，检查定位销是否断裂
  3. 检查刀架转动齿轮的齿面磨损情况
  4. 检查刀架内部是否有铁屑卡滞
- 解决方案：
  1. 定位销断裂 → 更换新定位销（Φ8×25，40Cr 调质处理）
  2. 锁紧螺母松动 → 拧紧螺母，扭矩 40N·m
  3. 铁屑卡滞 → 清理刀架内部铁屑，涂抹二硫化钼润滑脂

## 故障案例 4
- 设备型号：CK6132 普通车床
- 故障部位：尾座
- 故障现象：尾座套筒锁紧后仍能前后移动
- 可能原因：
  1. 锁紧手柄断裂
  2. 锁紧块磨损严重，夹紧力不足
  3. 套筒外圆磨损，与锁紧块配合间隙过大
- 排查步骤：
  1. 检查锁紧手柄是否有裂纹、断裂
  2. 松开锁紧手柄，测量锁紧块磨损量
  3. 用千分表测量套筒外圆的圆度和直线度
  4. 检查尾座体导轨面是否磨损
- 解决方案：
  1. 手柄断裂 → 更换锁紧手柄（HT200 材质）
  2. 锁紧块磨损 → 更换锁紧块，配作至套筒间隙 0.02mm
  3. 套筒磨损 → 套筒镀铬修复或更换新套筒

## 故障案例 5
- 设备型号：CK6132 普通车床
- 故障部位：冷却系统
- 故障现象：冷却液泵不工作，不出水
- 可能原因：
  1. 冷却液泵电机烧毁
  2. 叶轮卡住，被铁屑缠绕
  3. 供电线路断路或保险丝熔断
- 排查步骤：
  1. 检查配电柜对应保险丝是否熔断
  2. 用万用表测量冷却液泵电机绕组通断情况
  3. 拆开冷却液泵端盖，检查叶轮是否被铁屑卡住
  4. 检查冷却水箱液位是否过低
- 解决方案：
  1. 保险丝熔断 → 更换保险丝（10A）
  2. 叶轮卡滞 → 清理铁屑，清洗叶轮
  3. 电机烧毁 → 更换同型号电机（0.25kW，三相异步）

## 故障案例 6
- 设备型号：CK6132 普通车床
- 故障部位：主轴
- 故障现象：主轴旋转时振动大，加工工件出现波纹
- 可能原因：
  1. 主轴皮带轮不平衡
  2. 皮带张力不均匀
  3. 轴承游隙过大
  4. 工件装夹偏心
- 排查步骤：
  1. 关闭电源，用手转动主轴，检查是否有卡滞
  2. 调整皮带张力，检查四根皮带张紧度是否一致
  3. 用千分表测量主轴径向跳动（正常 ≤0.01mm）
  4. 检查卡盘装夹是否偏心
- 解决方案：
  1. 皮带问题 → 全部更换新皮带（B 型，根数 4）
  2. 轴承游隙大 → 调整轴承预紧力，拧紧主轴后端锁紧螺母
  3. 工件偏心 → 重新装夹，用千分表找正

## 故障案例 7
- 设备型号：CK6132 普通车床
- 故障部位：电气系统
- 故障现象：按下启动按钮，主轴不转，电机有"嗡嗡"声
- 可能原因：
  1. 主电机缺相运行（三相电源断一相）
  2. 接触器触点烧蚀，接触不良
  3. 电机绕组有短路故障
- 排查步骤：
  1. 用万用表测量三相电源电压，缺相则修复供电线路
  2. 检查交流接触器（型号 CJ20-25）触点是否烧蚀
  3. 测量电机三相绕组电阻，确认是否平衡
  4. 检查热继电器是否跳闸
- 解决方案：
  1. 缺相 → 修复电源线路，检查断路器
  2. 接触器烧蚀 → 更换接触器或打磨触点
  3. 电机短路 → 送修或更换主电机（2.2kW）

## 故障案例 8
- 设备型号：CK6132 普通车床
- 故障部位：导轨
- 故障现象：大拖板沿导轨移动时有扎刀现象
- 可能原因：
  1. 导轨面划伤、研伤严重
  2. 导轨间隙过大
  3. 溜板箱楔铁磨损
- 排查步骤：
  1. 用平尺检查导轨面直线度
  2. 检查导轨面是否有研伤、拉痕
  3. 用塞尺测量导轨间隙（正常 ≤0.02mm）
  4. 调整楔铁，检查磨损情况
- 解决方案：
  1. 导轨研伤 → 用金相砂纸研磨修复，涂抹导轨油
  2. 间隙过大 → 调整楔铁，保证间隙 0.01-0.02mm
  3. 楔铁磨损 → 更换楔铁配作

## 故障案例 9
- 设备型号：CK6132 普通车床
- 故障部位：操纵系统
- 故障现象：换向手柄扳动困难，有时卡滞
- 可能原因：
  1. 换向齿轮磨损，啮合不顺
  2. 拨叉轴弯曲变形
  3. 箱体润滑不足
- 排查步骤：
  1. 打开床头箱观察盖，手动扳动换向手柄
  2. 检查拨叉轴是否弯曲
  3. 检查齿轮端面磨损情况
  4. 补充床头箱润滑油
- 解决方案：
  1. 拨叉轴弯曲 → 校正或更换拨叉轴
  2. 齿轮磨损 → 更换磨损齿轮
  3. 润滑不足 → 补充 L-AN46 全损耗系统用油

## 故障案例 10
- 设备型号：CK6132 普通车床
- 故障部位：卡盘
- 故障现象：三爪卡盘夹紧后工件仍能转动
- 可能原因：
  1. 卡盘爪磨损严重，夹紧面光滑
  2. 卡盘内部齿轮传动磨损，夹紧力不足
  3. 卡盘与主轴连接松动
- 排查步骤：
  1. 检查卡盘爪夹紧面是否有凹槽、毛刺
  2. 拆开卡盘后盖，检查内部齿轮磨损
  3. 检查主轴法兰与卡盘连接螺栓
- 解决方案：
  1. 爪面光滑 → 在夹紧面车出交叉网纹，增加摩擦力
  2. 夹紧力不足 → 更换卡盘（型号 K11250）
  3. 连接松动 → 重新紧固螺栓，扭矩 60N·m

# CK6140 数控车床故障手册

## 故障案例 11
- 设备型号：CK6140 数控车床
- 故障部位：主轴伺服系统
- 故障现象：主轴启动缓慢，加速时报警"主轴伺服过载"
- 可能原因：
  1. 主轴伺服电机编码器故障
  2. 伺服驱动器参数设置不当
  3. 主轴箱内部有零件卡滞
  4. 冷却液进入伺服电机
- 排查步骤：
  1. 查看数控系统报警代码（FANUC 0i-MF：报警 410/411 为伺服过载）
  2. 打开主轴箱盖，手动转动主轴确认是否有卡滞
  3. 检查伺服电机编码器连接插头是否松动
  4. 检查电机定子是否受潮进水
- 解决方案：
  1. 编码器松动 → 重新紧固编码器并做原点复归
  2. 参数不当 → 检查 FANUC 参数 P2040（电流限制值），调整至额定电流的 1.2 倍
  3. 电机进水 → 拆开电机烘干，更换密封件

## 故障案例 12
- 设备型号：CK6140 数控车床
- 故障部位：X 轴进给
- 故障现象：X 轴移动时出现爬行，定位精度超差
- 可能原因：
  1. X 轴导轨润滑不足
  2. 滚珠丝杠预紧力不够
  3. 伺服参数位置环增益（Kp）设置过低
  4. 导轨直线度误差大
- 排查步骤：
  1. 检查集中润滑系统油位和管路是否堵塞
  2. 用千分表测量 X 轴定位精度（正常 ≤0.003mm）
  3. 查看 FANUC 系统参数 P1825（位置增益）
  4. 用激光干涉仪测量导轨直线度
- 解决方案：
  1. 润滑不足 → 清洗润滑管路，补充润滑油
  2. 预紧力不够 → 调整丝杠预紧螺母，保证预紧量 0.02-0.03mm
  3. Kp 值低 → 逐步增加 P1825，每次增加 50，观察是否振荡

## 故障案例 13
- 设备型号：CK6140 数控车床
- 故障部位：刀塔
- 故障现象：伺服刀塔换刀错位，刀具装夹不到位
- 可能原因：
  1. 刀塔分度编码器松动
  2. 刀塔锁紧油缸压力不足
  3. 刀具固定螺栓松动
  4. 刀塔内部定位销磨损
- 排查步骤：
  1. 在 MDI 模式下执行换刀指令，观察刀塔分度精度
  2. 检查液压系统压力（正常 ≥4MPa）
  3. 手动检查各刀具固定状态
  4. 拆下刀塔端盖，检查定位销磨损
- 解决方案：
  1. 编码器松动 → 重新紧固，执行刀塔原点校准
  2. 液压压力不足 → 调整溢流阀，提升系统压力至 4.5MPa
  3. 刀具松动 → 紧固固定螺栓，扭矩 30N·m

## 故障案例 14
- 设备型号：CK6140 数控车床
- 故障部位：刀架
- 故障现象：刀架刀套破损，刀具脱落
- 可能原因：
  1. 换刀时主轴未完全停止
  2. 刀具装入时刀柄锥面有铁屑
  3. 刀套本身存在制造缺陷
  4. 主轴锥孔磨损，刀柄配合间隙大
- 排查步骤：
  1. 查看数控系统日志，确认换刀时主轴转速是否为 0
  2. 检查刀套锥面是否有铁屑残留
  3. 用锥度塞规检查主轴锥孔磨损情况
- 解决方案：
  1. 换刀参数调整 → FANUC 参数 P1620（换刀等待时间）适当增大
  2. 清洁刀套 → 用无尘布蘸酒精清洁主轴锥孔和刀柄锥面
  3. 主轴锥孔磨损 → 主轴锥孔研磨修复

## 故障案例 15
- 设备型号：CK6140 数控车床
- 故障部位：润滑系统
- 故障现象：集中润滑系统报警，X/Z 轴导轨缺油
- 可能原因：
  1. 润滑泵电机烧毁
  2. 分配器堵塞
  3. 润滑油管路破裂
  4. 润滑油液位过低
- 排查步骤：
  1. 查看系统报警代码"EMG-30"或润滑系统指示灯
  2. 检查油箱油位（正常 ≥2/3）
  3. 检查各分配器是否出油
  4. 检查管路是否有渗漏
- 解决方案：
  1. 电机烧毁 → 更换润滑泵电机（0.2kW）
  2. 分配器堵塞 → 拆下分配器清洗，用压缩空气吹通
  3. 管路破裂 → 更换同规格油管，管接头用生胶带密封

## 故障案例 16
- 设备型号：CK6140 数控车床
- 故障部位：Z 轴
- 故障现象：Z 轴回零不准，每次回零位置相差 0.1mm 左右
- 可能原因：
  1. Z 轴原点开关松动
  2. 原点开关凸轮磨损
  3. 滚珠丝杠热伸长补偿值设置错误
  4. 伺服编码器零位漂移
- 排查步骤：
  1. 连续执行 5 次 Z 轴回零，用千分表测量位置偏差
  2. 检查原点开关安装螺栓是否松动
  3. 查看 FANUC 参数 P1851（参考点偏移量）
  4. 检查温度补偿参数 P1950-P1959
- 解决方案：
  1. 开关松动 → 紧固螺栓，重新调整开关位置
  2. 热伸长补偿 → 根据丝杆温升修改温度补偿表
  3. 编码器漂移 → 重新设置编码器原点（FANUC：手动回零后执行 P1815.2=0 再=1）

## 故障案例 17
- 设备型号：CK6140 数控车床
- 故障部位：系统
- 故障现象：FANUC 系统黑屏，按任意键无反应
- 可能原因：
  1. 系统控制单元保险丝熔断
  2. 系统 CPU 板故障
  3. 显示器信号线松动
  4. 系统参数异常死机
- 排查步骤：
  1. 断电后重新上电，观察系统是否正常启动
  2. 检查控制柜内 FANUC 系统电源指示灯（绿=正常，红=故障）
  3. 检查显示器 VGA 连接电缆
  4. 打开系统单元盖，检查 CPU 板和电源板指示灯
- 解决方案：
  1. 参数异常死机 → 同时按住 RSET 和 DELETE 键上电启动，清除参数后重设
  2. 保险丝熔断 → 更换保险丝（2A，慢熔）
  3. CPU 板故障 → 联系 FANUC 售后更换（型号 A20B-8200-0391）

## 故障案例 18
- 设备型号：CK6140 数控车床
- 故障部位：气动系统
- 故障现象：卡盘夹紧力不足，加工中工件飞出
- 可能原因：
  1. 气源压力低于 0.5MPa
  2. 气动卡盘密封件损坏漏气
  3. 电磁阀动作不良
  4. 卡盘夹紧行程不足
- 排查步骤：
  1. 检查气源压力表（正常 0.5-0.6MPa）
  2. 听气动卡盘是否有漏气声
  3. 用万用表检查电磁阀线圈通断
  4. 检查卡盘行程开关是否正常触发
- 解决方案：
  1. 气压低 → 调整气源减压阀至 0.55MPa
  2. 密封件损坏 → 拆开卡盘更换密封圈（NBR 丁腈橡胶）
  3. 电磁阀故障 → 更换电磁阀（型号 4V210-08）

## 故障案例 19
- 设备型号：CK6140 数控车床
- 故障部位：防护门
- 故障现象：防护门打开后机床无法启动，"安全联锁报警"
- 可能原因：
  1. 防护门限位开关损坏
  2. 限位开关安装位置偏移
  3. 安全继电器故障
- 排查步骤：
  1. 关闭防护门，手动按下限位开关，检查是否能启动
  2. 用万用表测量限位开关通断
  3. 查看 PLC 输入指示灯（X0.0 为防护门信号）
- 解决方案：
  1. 开关损坏 → 更换限位开关（型号 SN04-N，电感式）
  2. 位置偏移 → 重新调整开关安装位置，确保关门时能可靠触发
  3. 安全继电器故障 → 检查继电器输入输出信号，更换继电器

## 故障案例 20
- 设备型号：CK6140 数控车床
- 故障部位：主轴
- 故障现象：主轴转速不稳定，设定 3000 转实际只有 2800 转
- 可能原因：
  1. 主轴编码器信号异常
  2. 伺服参数速度增益（Kv）设置过低
  3. 主轴皮带打滑
  4. 负载过重超过额定功率
- 排查步骤：
  1. 在系统诊断界面查看主轴实际转速反馈值
  2. 检查 FANUC 参数 P2044（速度增益 Kv）
  3. 打开皮带防护罩，检查皮带张紧度
  4. 确认切削参数是否在额定负载内
- 解决方案：
  1. Kv 值低 → 逐步增加 P2044，每次增加 100，观察是否振荡
  2. 皮带打滑 → 调整电机座位置张紧皮带，或更换皮带
  3. 过载 → 降低切削深度或进给速度
